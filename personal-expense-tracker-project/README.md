# Personal Expense Tracker

A beginner-friendly expense tracker built using Python. It allows users to manage their personal expenses through a menu-driven program.

## Features
- Add expenses with amount, category, description, and date.
- View all recorded expenses.
- Calculate total spending.
- View spending summaries by category.
- Delete an expense.
- Edit an existing expense.
- Save and load expenses using a JSON file.
- Validate user input, including amounts and dates.

## Concepts Used
- Variables and data types
- Lists and dictionaries
- Loops and conditional statements
- Functions
- Exception handling
- File handling
- JSON data storage
- Date and time handling
