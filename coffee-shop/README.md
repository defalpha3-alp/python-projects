# Coffee Shop Ordering System

A simple coffee shop ordering system built using Python. Customers can select coffee, order pastries or snacks, and view their bill.

## Features
- Display the coffee menu with prices.
- Display pastries and snacks with prices.
- Select coffee by name.
- Enter item quantities.
- Add multiple coffee items to an order.
- Optionally add pastries or snacks.
- Validate user input.
- Generate separate coffee and snack bills.
- Calculate and display the final bill.

## Concepts Used
- Variables and data types
- Dictionaries and lists
- Tuples
- Loops and conditional statements
- Functions
- User input and validation
- Dictionary iteration
- Calculations
