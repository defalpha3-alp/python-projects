# Python Projects

A collection of Python projects built to practise programming fundamentals, strengthen problem-solving skills, and develop practical applications.

## Projects

### 1. Number Guessing Game
A simple game where users guess a randomly generated number using hints and conditional logic.

### 2. Random Password Generator
Generates random 12-character passwords using uppercase and lowercase letters, digits, and punctuation symbols.

### 3. Personal Expense Tracker
A menu-driven application to add, view, edit, and delete expenses, calculate total spending, and summarize expenses by category. Data is stored in JSON for persistence between sessions.

### 4. Coffee Shop Ordering System
A console-based ordering system featuring coffee, pastries, and snacks, with quantity validation, order management, and automatic bill calculation.

## Technologies & Concepts

- **Language:** Python
- **Tools:** Git and GitHub
- **Concepts:** Functions, loops, conditional statements, data structures, input validation, exception handling, file handling, and JSON persistence.

## Purpose

This repository documents my progress in Python through hands-on projects, with a focus on writing functional code and applying programming concepts to practical problems.
